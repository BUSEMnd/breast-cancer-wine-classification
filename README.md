## Project Overview
This repository contains the Machine Learning Midterm assignment evaluating Decision Tree, KNN, Naive Bayes, and K-Means algorithms on Breast Cancer Wisconsin and Wine Classification datasets across 3 stratified seeds (42, 52, 62) with 144 total model fits.

## How to Run
1. Install dependencies: `pip install -r requirements.txt`
2. Run `breast_cancer.ipynb` and `wine.ipynb` sequentially.
